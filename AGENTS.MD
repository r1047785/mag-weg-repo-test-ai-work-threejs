## git commit messages

- use conventional commit messages
- follow the format: <type>(<scope>): <subject>
- type: chore, feat, fix, docs, style, refactor, perf, test
- keep commit messages concise and descriptive

- use feat for new features
- use fix for bug fixes

## shader syntax

- use tsl (Three.js Shader Language)

## security guidelines

- never commit secrets or sensitive information to the repository
- always use environment variables or secure vaults for sensitive data
